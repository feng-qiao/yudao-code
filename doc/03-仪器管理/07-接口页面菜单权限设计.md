# 一、设计约定

## 1.1 接口风格（沿用 lab 模块实证）

| 项 | 约定 |
| --- | --- |
| 前缀 | 管理后台统一 `/admin-api`（前端 `request` 已含前缀，业务 URL 从 `/lab/instrument/...` 起） |
| 方法 | 查询 GET、新增/删除 POST、修改 PUT、导出 GET+download |
| 返回 | `CommonResult<T>` / `CommonResult<PageResult<T>>` |
| 分页参数 | `pageNo` / `pageSize` + 业务筛选 |
| 鉴权 | `@PreAuthorize("@ss.hasPermission('...')")` |
| 审计 | 写操作加 `@OperateLog` |
| 事务 | 涉及多表写入/并发校验加 `@Transactional` |
| 幂等 | 高频/易重提交接口加 `@Idempotent` |

## 1.2 权限编码规范

格式：`lab:instrument:<模块>:<动作>`（与前端 `v-hasPermi`、`system_menu.permission` 三者一致）。

模块取值：`platform` / `device` / `room` / `manager` / `notice` / `qualification` / `credit` / `suspend` / `reservation` / `maintenance` / `freeze` / `repair` / `stat`。

动作取值：`query` / `create` / `update` / `delete` / `audit` / `apply` / `cancel` / `adjust` / `export` / `manage` / `supplement` / `handle` / `transfer`。
