# 一、分批原则

1. **按业务闭环分批，不按字段/接口切碎**：每一批交付"可被业务方验收的一个完整能力"，而非零散的技术点。
2. **依赖优先**：后批依赖前批已冻结的表结构与接口契约；无依赖的批次可并行。
3. **未确认参数不得启用**（F13/F14/F15）：涉及 U1/U2/U3 的能力，代码须支持配置，但**未配置时不可预约**，不得以默认值上线。
4. **每批均含**：后端接口 + 前端页面 + 权限串 + 操作日志 + 自测；批次末尾**前端验收通过**后再进入下一批（遵循既有项目流程）。
5. **允许按真实依赖微调**：若实施中发现某批可合并或须拆分的更细，**以实际依赖关系为准**调整，但不得改变业务功能覆盖范围（07 文档页面清单不得遗漏）。
