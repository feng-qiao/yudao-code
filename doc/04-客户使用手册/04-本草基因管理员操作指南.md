# 04 本草基因管理员操作指南

> 本指南面向"本草基因管理员"（lab_admin）——实验室日常运行的管理者。
> 本草基因管理员**不是**系统管理员（租户管理员）：账号体系、角色权限、租户参数等"平台本身"的事归租户管理员管；您负责的是**实验室业务**的运转。
> 编制日期：2026-10-20 ｜ 全部操作按当前实际系统核验。

---

## 1. 您的角色与权限概览

登录本草基因管理员账号后，您可以：

| 板块 | 您能做 |
|---|---|
| 仪器档案 | 平台、房间、设备档案的新增/编辑/删除；设备状态流转；使用须知发布 |
| 仪器负责人 | 分配/解除设备负责人、平台负责人、维修负责人（历史留痕） |
| 预约体系 | **配置每台设备的预约规则与开放窗口（唯一拥有此菜单的角色）**；管理全部预约（取消/调整/完成/作废/历史） |
| 资质 | 审批全部资质申请、撤销资质 |
| 信用 | 查看全部信用账户与流水、人工加扣分、导出流水 |
| 暂停 | 创建/解除任意范围的使用暂停 |
| 质粒 | 全流程：类型维护、审核、库存、借还审批、违规、黑名单、存放位置 |
| 注册审批 | 审批新用户注册申请 |
| 用户管理 | 新增/编辑/停用用户、重置密码、分配角色（缺"恢复已删用户"） |
| 角色管理 | **只读查看**（不能改角色与菜单权限） |
| 公告 | 发布维护实验室公告 |

**您没有的**：菜单/部门/岗位/字典/租户等系统管理菜单；角色管理写权限；"用户恢复"按钮。

> 与租户管理员的完整对比见《01-平台功能与角色权限总览》4.1 节。

## 2. 初始化实验室（第一次用系统时做一遍）

完整步骤参见《02-仪器管理从零开始完整操作手册》场景 1~5，此处给检查清单：

- [ ] **仪器平台**：建好业务平台（编码唯一、状态启用）
- [ ] **实验室/房间**：建好房间（编码唯一、状态启用）
- [ ] **仪器设备**：逐台建档（编号/名称/类别/平台/房间/图片；"允许预约"开关仅档案标记）
- [ ] **使用须知**：为设备编写并发布须知（选做但强烈建议）
- [ ] **预约配置**：为每台要开放的设备配置并**启用**预约规则（不配 = 不开放）
- [ ] **仪器负责人**：指定设备/平台负责人；为房间指定维修负责人
- [ ] **注册审批**：确认有审批人（您自己或注册审批专员）
- [ ] **实验室公告**：发布使用制度等公告（选做）

## 3. 日常管理操作

### 3.1 审批使用资质（高频）
「资质审核」→"申请审核"页签 →「审核」→ 通过（可填"有效期至"，不填=长期）或驳回（意见必填）。
- 通过后系统自动初始化该用户信用账户（首次 100 分）。
- "资质列表"页签可撤销生效中资质（原因必填）——适用于成员离组、长期违规等。
- 详细步骤：02 册场景 6/7。

### 3.2 管理预约（高频）
「预约管理」→ 全部预约可见。可做：
- **取消**（原因必填，管理侧不受"开始前"限制）；
- **调整**（可改时间/换设备，系统全链复核，原因必填）；
- **完成**（使用结束后登记**实际起止时间**——必填；系统无自动完成）；
- **作废**（约了没用/录错，原因必填，二次确认，不可恢复）；
- **历史**（每条预约全部动作留痕）。

### 3.3 配置/调整预约规则
「预约配置」→ 顶部选设备 → "预约规则"页签改粒度/时长/开放日/时段/范围 → 保存。
- 关闭"规则启用"开关即可临时下线该设备的预约。
- 注意"允许开始后管理员调整"开关：开启后已开始的预约管理侧仍可调整。

### 3.4 信用管理
「信用管理」→ 加扣分（变动值不能为 0、原因必填、允许负分）；流水可导出 Excel；流水不可改。
- 低分不会自动触发任何限制——需要限制时用"暂停"。

### 3.5 暂停与解除
「暂停管理」→「创建暂停」：
- 范围选**单仪器**（需对该设备有管理权）或**全部仪器**；
- 时长：预设档位（1/3/7/14/30 天）或自定义计划结束时间，**二选一**；
- 原因必填。创建即生效、立即拦截该用户新预约，并自动暂停其生效中资质。
- **到期不会自动解除**，务必人工「解除」（原因必填）；解除后未被其他暂停覆盖的资质自动恢复。

### 3.6 设备状态流转（故障/维护/停用/报废）
「仪器设备」→ 行内「状态」按钮 → 选择目标状态：
- 正常 / 维护 / 故障 / 停用 之间可互转；**仅"停用"可进"报废"（终态）**；
- 同状态重复设置自动忽略；
- 删除设备档案：仅"停用/报废"可删，且须先解除其全部生效负责人。
- **维修工单未上线**：故障后请线下联系房间维修负责人（房间列表可查），修复后手动改回"正常"。

### 3.7 仪器负责人维护
「仪器负责人」→「分配负责人」（范围/目标/类型/负责人）或「解除」（原因必填）→「历史」查全程。
- 设备/平台负责人重复分配自动顶替原负责人；维修负责人可多名并存。

### 3.8 注册审批
「系统管理 → 注册审批」→ 默认显示待审批 →「详情」核对材料 →「通过」（可选意见）或「驳回」（意见必填）。
- 通过即自动建号并授予"普通用户"角色，新成员用注册密码直接登录；
- 通过的用户**没有部门/岗位**，如需归属请到「用户管理」编辑补录；
- 被驳回的申请由申请人自行修改重提，您无需操作。

### 3.9 用户管理
「系统管理 → 用户管理」：新增用户（部门/岗位/角色）、编辑、停用/启用、重置密码、导入导出。
- 给成员授予"仪器设备负责人"角色也在这里（编辑 → 分配角色）。

### 3.10 实验室公告
「实验室公告管理」→ 新增/编辑/删除/导出。公告只在本菜单内展示，无推送，请线下告知成员查看。

## 4. 质粒管理职责

本草基因管理员在质粒模块拥有全部权限（详见《07-质粒管理操作指南》）：

| 事务 | 入口 | 要点 |
|---|---|---|
| 建类型并指定库管员 | 质粒类型 | 类型库管员决定后续审核/出入库由谁做 |
| 审核入库 | 质粒审核 | 通过必填"初始库存确认数量"与存储核查；您可跨类型审核 |
| 库存事务 | 库存台账 | 查看不受限；**直接出入库/盘点/调整写操作仍须该类型库管员**（管理员不自动获得） |
| 借用/归还审批 | 质粒借用/归还 | 驳回必填意见；通过借用即自动出库、通过归还即自动入库 |
| 违规/黑名单 | 违规记录/借用黑名单 | 人工登记仅"归还不合规/其他"两类；黑名单生效即拦截借用 |
| 存放位置 | 存放位置 | 查看与修改全部质粒位置 |

## 5. 管理员的每日/每周节奏建议

```
每天：注册审批（有则处理）→ 资质审核 → 预约管理（完成昨日的、处理异常）
每周：核对设备状态与预约规则 → 检查信用流水 → 检查暂停到期情况（人工解除）
随时：公告发布、负责人调整、用户停用/重置密码
```

## 6. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 设备在大厅不显示/不可预约 | 检查预约规则是否启用；设备状态是否正常 |
| 用户说约不了 | 按顺序查：资质 → 暂停 → 设备状态 → 规则开放时段 → 开关 116 |
| 角色管理里不能改权限 | 正常现象，本草基因管理员只读；请联系租户管理员 |
| "预约配置"菜单只有我有 | 是的，租户管理员和设备负责人都没有 |
| 暂停到期了还拦截用户 | 本版本到期不自动解除，请人工"解除" |
| 删除设备失败 | 先解除其全部生效负责人，且状态须为停用/报废 |
| 用户忘记密码 | 用户管理 → 重置密码 |
| 注册审批通过后用户没有部门 | 系统设计如此，请在用户管理手工补录 |
