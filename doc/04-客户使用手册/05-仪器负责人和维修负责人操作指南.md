# 05 仪器负责人和维修负责人操作指南

> 本指南面向两类"负责人"：**仪器设备负责人**（对某台/某平台设备负责）和**实验室维修负责人**（对某间实验室的维修事务负责）。
> 两者都由管理员在「仪器负责人」页面指定，但职责、权限和当前实现程度完全不同——请务必读完本指南再上手。
> 编制日期：2026-10-20 ｜ 全部内容按当前实际系统核验。

---

## 1. 先理解："角色"和"负责人关系"是两个条件

系统能否让您管理某台设备，同时取决于：

1. **角色**：您是否被授予了"仪器设备负责人"角色（或管理员角色）——决定您能不能看到"资质审核""预约管理"这些菜单；
2. **负责人关系**：管理员是否在「仪器负责人」页面把您指定为某设备的负责人——决定您在这些菜单里能看到**哪些设备**的数据。

| 情况 | 结果 |
|---|---|
| 有角色，无关系 | 菜单能看到，但列表是空的 |
| 有关系，无角色 | 菜单都看不到（不能审批资质、不能管预约） |
| 两者都有 | 可以对该设备的资质申请和预约进行管理 |

> **被解除负责人关系后**：该设备的数据立即从您的列表消失，按钮失效；历史记录仍在系统中保留，可由管理员追溯。
> **角色被移除后**：菜单消失，即使负责人关系还在也无处操作。

## 2. 仪器设备负责人

### 2.1 谁可以被指定
本租户内处于启用状态的任何用户；管理员在「仪器负责人」→「分配负责人」中选择：授权范围 = **设备负责人**（单台）或**平台负责人**（一个平台下的全部设备）、目标、类型（主负责人/备用负责人）、负责人。
- 同一设备/平台的同类型负责人重复分配时，**自动解除原负责人**并保留历史。

### 2.2 您能做什么（角色 908 实测菜单）
登录后您可见 5 个业务菜单：

| 菜单 | 您能做的事 |
|---|---|
| 仪器设备 | 查看设备档案（含自己负责的设备） |
| 我的使用资质 | 查看本人资质、申请资质（您同时也是普通用户身份时） |
| 资质审核 | **审批自己负责设备**的资质申请（通过/驳回/历史） |
| 预约管理 | **管理自己负责设备**的预约：取消/调整/完成/作废/历史 |
| 我的预约 | 查看本人预约 |

> 注意：仪器设备负责人**没有**"仪器大厅""设备详情""预约配置""信用管理""暂停管理"菜单。

### 2.3 审批资质
1. 「资质审核」→"申请审核"页签 → 只看到自己负责设备的申请。
2. 「审核」→ 通过（可填"有效期至"，不填长期）或驳回（**意见必填**）。
3. 通过后系统自动为申请人初始化信用账户（首次 100 分）。

### 2.4 管理预约
1. 「预约管理」→ 只看到自己负责设备的预约（以及自己的预约）。
2. 按钮与规则同管理员：**取消/调整**（管理侧原因必填）、**完成**（实际起止必填）、**作废**（原因必填、二次确认）、**历史**。
3. 您**不能**修改预约规则（无"预约配置"菜单）；需要改规则请联系本草基因管理员。

### 2.5 信用与暂停的有限权限
虽然没有这两个菜单，但后端为您保留了有限的管理能力：
- **信用调分**：可以对"在您授权设备上持有生效/已暂停资质的用户"调分（通过接口；日常如需调分可联系管理员代操作）；
- **暂停**：可以创建"**单仪器**"暂停（仅限您负责的设备）；**"全部仪器"暂停仅管理员可做**。

### 2.6 边界清单（不能做）
- 不能查看/管理未授权设备的任何数据；
- 不能新增/编辑设备档案、状态流转（"状态"按钮需设备管理权限）；
- 不能配置预约规则、发布使用须知；
- 不能审批注册、管理用户。

## 3. 实验室维修负责人

### 3.1 如何被指定
管理员在「仪器负责人」→「分配负责人」中：授权范围 = **实验室维修负责人**、目标 = 房间、类型 = 维修负责人。
- **一间实验室允许多名维修负责人同时生效**（实测环境中一个房间有 2 名生效中的维修负责人）。
- 配好后，房间列表的"维修负责人"列会显示您的姓名和电话。

### 3.2 当前维修流程的实现程度（重要，如实说明）

> **当前版本没有"维修工单"功能。** 系统已预留维修数据表（维护时段记录），但没有故障登记页面、没有维修任务分派、没有维修处理操作。您被指定为维修负责人后，**在系统内暂时没有专属的维修操作界面**。

当前实际的故障处理流程是"线下处理 + 管理员改状态"：

```
设备故障被发现
    → 联系房间维修负责人（房间列表可查姓名电话）【线下】
    → 管理员在「仪器设备」用「状态」按钮把设备改为"故障"或"维护"
      （此后设备不可被新预约）
    → 维修负责人线下组织维修
    → 修复后由管理员把设备状态改回"正常"，设备恢复可预约
```

### 3.3 维修负责人与设备负责人的区别

| 对比项 | 设备负责人 | 维修负责人 |
|---|---|---|
| 挂靠对象 | 单台设备或平台 | 实验室（房间） |
| 人数限制 | 同类型 1 人（再分配自动顶替） | 可多名同时生效 |
| 系统操作 | 审资质、管预约 | **当前无系统内操作**（预留） |
| 典型职责 | 设备日常使用管理 | 设备故障的线下维修组织 |

### 3.4 哪些操作必须由管理员完成
- 设备状态流转（故障/维护/恢复正常）——需要"设备管理"权限，仅管理员可操作；
- 维修期间的时间记录——当前系统无维修登记入口，如需留档请线下记录；
- 后续版本若上线维修工单，本指南将更新。

## 4. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 我有负责人角色但"资质审核"里看不到申请 | 您还不是任何设备的负责人，请管理员在"仪器负责人"页面为您建立关系 |
| 管理员说已给我建了关系，但我看不到菜单 | 您缺少"仪器设备负责人"角色，请联系管理员分配角色 |
| 我被解除了负责人，之前的审批记录还在吗 | 系统保留历史，但您不再能访问该设备数据 |
| 能同时负责多台设备吗 | 可以，每台设备一条负责人关系；平台负责人则自动覆盖该平台下全部设备 |
| 设备坏了我在系统里登记一下？ | 当前版本无维修登记功能；请线下联系维修负责人，并由管理员改设备状态 |
| 我能替管理员审批注册申请吗 | 不能，注册审批是管理员/审批专员的权限 |
